# 📚 Library Catalogue

A functional static web application for browsing and searching a digital library catalogue.

## Live Demo

[View the Library Catalogue](https://is-project-2026.github.io/library-catalogue-169390/)

## Features

- Browse available books
- Search by title or author
- Filter books by category
- View book availability
- Borrow available books
- Responsive layout for desktop and mobile
